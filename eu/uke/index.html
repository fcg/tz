英国创新创始人签证

签证发展历程

  • 2008年，Tier 1 签证正式设立
  • 2011年3月，投资额超过500万英镑或雇佣超过10名员工，可在3年后获得英国永居；
  • 2012年4月，持Tier 1 PSW的申请者投资5万英镑即可申请企业家，但是PSW随即在2014年7月8日取消；
  • 2012年12月，降低语言要求，从7分降至4分；
  • 2014年年初，内政部引入企业家真实性测试；
  • 2015年4月，内政部要求递交签证的时候提供商业计划书同时提供90天资金证明；
  • 2018年1月，每位申请人都需要满足每年离开英国不超过180天；
  • 2019年3月29日，取消Tier 1 Entrepreneur类别换成全新的Innovator Visa创新签证；
  • 2020年12月1日，Innovator Visa创新签证改为PBS记点积分制；
  • 2023年4月13日，Innovator Visa创新签证变更为Innovator Founder Visa创新创始人签证。

项目介绍

2023年4月13日，英国内政部官网发布新政公告，将创新签证名字变更为创新创始人签证，取消5万英镑投资额。执行时间为2023年4月13日。

相比于原创新签证，新的创新创始人签证更加的灵活，放宽了对于申请人工作的要求，申请人在满足要求的情况下，可以寻求第二份工作，续签周期为“3+3+3..."。此外，如果满足新政永居条件，三年即可申请永居；该项目还需要由第三方对企业创新性、可行性和可发展性进行评估和背书。

申请条件

  1. 创业：提供背书信（通过背书机构审批BP）；
  2. 语言：B2考试，相当于签证类雅思5.5分，英语国家本科以上学位免考；
  3. 年龄：主申请人18周岁以上，可携带配偶和18周岁以下的子女；
  4. 生活保证金：全球任意银行存满28天，主申请人：1270镑，附属申请人：285镑。

申请流程

文案服务：

  1. 签约；
  2. 材料收集，银行开户；
  3. 存入生活费，存入投资款，申请材料准备；
  4. 企业材料整合；
  5. 材料翻译，全套材料整合；
  6. 递交背书机构，申请背书；
  7. 面试，拿到背书信；
  8. 递交签证申请，获批。

商业服务：

  1. 英国商业咨询；
  2. 合作项目接洽；
  3. 项目跟进协助沟通；
  4. 商业培训。

整体周期：4-6个月

申请绿卡

  1. 背书：持有有效的背书信；
  2. 语言：life in the UK + B1;
  3. 居住：任意连续365天累积离境不超过180天；
  4. 无犯罪：在英国无犯罪记录；
  5. 创业条件（7选2）：
    • 投资至少5万英镑到相关企业，积极投入推进Endorsing Body背书认可的商业计划；
    • 企业的客户数量在近3年至少翻一倍，且高于其他英国公司的客户平均数量；
    • 获得背书的商业中，有重大研发并已申请专利知识产权保护；
    • 该公司业务在最后一个财年至少有100万英镑的年营业额；
    • 该公司业务在最后一个财年至少有50万英镑的年营业额，其中至少10万英镑来自出口海外所得；
    • 该公司至少创造10个本地就业岗位；
    • 该公司至少创造5个本地就业岗位并且年工资金额不低于2万5千英镑。

申请入籍

  1. 拿到永居满一年才可以申请；
  2. 从入籍申请之日起，在过去英国居住的5年中，申请人累积离境时间不得超过450天；
  3. 从入籍申请之日起，往回看12个月，申请人累积离开英国的时间不超过90天；
  4. 语言要求：life in the UK + CEFR B1(4分）。

项目优势

  1. 更加人性化：允许申请人满足要求的情况下，有第二份工作；
  2. 投资用途更加灵活：法案针对创业部分提供7选2解决方案；
  3. 加入政府背书环节降低风险：项目需要通过Endorsing Body审查和批准；
  4. 申请周期和转永居时间缩短：4-6个月即可获得身份，3年即可转绿卡。
  5. 超高性价比，工作身份两不误：
    • 仅需3年即可获得绿卡，且申请人可以比较灵活操控获得绿卡的方式，可以允许申请人有第二份工作；
    • 先拿省份后投资，登陆后6个月内完成董事注册，以合伙人和创始人身份进驻公司参与运营管理；
    • 项目稳定性更高，专业资深商业团队保驾护航，前期投资，后期赚钱；
    • 不仅拿到签证身份，同时有机会参与政府投资计划，积累企业家经验，收获极好的事业发展机会；
    • 高福利，拿到第一个身份即可全家享受英国免费公立教育以及NHS全民医疗服务体系。

关于背书

  1. Endorsing Body职责
    • 首次签证：取代旧政策的企业家真实性测试，审核客户商业计划书的可行性，之后移民局不再审核商业部分；
    • 创业期间：定期跟进指导客户的创业进度，设置节点考察企业和客户情况，实现投后管理（12个月，24个月）；
    • 续签/永居：在申请人续签/永居申请节点，更新发放背书函。
  2. 关于背书说明
    • 名额：共4家背书机构，数量不设置上限（可能会有更新，以官网为主）；
    • 特点：每个背书机构可以自行决定发放背书名额无需通过移民局审批。
